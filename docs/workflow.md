# Video workflow

1. Read the user's prompt and extract topic, audience, duration, language, platform and requested voice characteristics.
2. Create the hook, script and storyboard.
3. Prepare licensed visual assets and narration audio. For AI voice, inspect Shotstack's currently available models/options; choose a compatible natural voice based on the prompt. If no voice is specified, choose one suitable for the content.
4. Build an Edit JSON with video, image, audio, subtitle and title clips as required.
5. Set output to MP4, 9:16, HD and a suitable frame rate.
6. Submit to Shotstack and check status.
7. Deliver the final rendered output and ask the user to review it.
8. The user publishes manually. Never auto-publish.
